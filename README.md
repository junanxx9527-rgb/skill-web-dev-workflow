# web-dev-workflow

一个面向 **Claude Code** 的 Skill:把"网站 / Web 应用开发"沉淀成一套可复用的工作流规范。

它要解决的不是"怎么写代码",而是真实开发里最耗人的那部分——**反复提醒**:接口要一个个点名、常见页面要催才做、安全和优化总是事后补、定过的约定换个任务又被问一遍。本 skill 让 Claude 把这些"常识性配套工作"主动做全,把"定过的约定"全程遵守。

> 核心理念:**用户点名的是一个功能的"名字",交付的应该是真实产品里这个功能"本来就该有的样子",而不是 demo。**

## 它会做什么

- **启动对齐一次到位**:新项目先一轮结构化对齐(类型、技术栈、用户系统、i18n、部署),结论写进约定文档,之后不再重复问。已有项目则读代码推断约定、复述确认,不重新问卷。
- **技术栈按项目推导,且对"不懂的用户"友好**:用户有偏好就照办;不懂技术就由 Claude 按项目类型推导,只用人话讲理由,不甩技术名词逼用户选。
- **把单点需求扩展成完整闭环**:接到"加个评论功能",自动推导出列表/分页/删除/校验/空态/失败提示/权限边界等配套,并按改动体量分级确认(小的直接做,大的先说一句再做)。
- **第一次就建立可复用模式**:统一错误格式、输入校验、前端请求封装层、表单模式、页面三态——给出栈无关的契约 + Next.js/Vue 现货示例,之后加同类东西变成填空题。
- **安全是写代码时就落地的**:服务端校验、防注入/XSS/CSRF、鉴权与水平越权、密钥进 env、限流等默认执行。
- **站点级能力主动补**:深色模式、404/500、SEO、favicon、设置页等在合适时机主动列给用户勾选。其中 **favicon 放到项目基本完工时再做**,按用户思路与难度分流(简约的 Claude 直接做,太难的给定制提示词让用户去图像工具生成)。
- **交付前自查**:汇报"做完"前跑 typecheck/build/lint/test、给关键路径补测试、过一遍自查清单,**如实汇报跑了什么、结果如何**。

## 设计基准:可升级的 MVP

本 skill 大量场景是做 MVP,但这里的 MVP 有明确定义:

> **MVP = 范围精简,但地基是生产级的、能在源码基础上直接往上长的成品雏形——不是用完即弃、以后要重写的原型。**

一句话:**砍范围,不砍质量。** 少做功能可以,埋下要返工的烂地基不行。

## 目录结构

```
web-dev-workflow/
├── SKILL.md                          # 入口:工作流总览、触发点、跨领域原则、引用索引
└── references/
    ├── intake.md                     # 启动对齐:新项目/已有项目,技术栈分情况推导
    ├── feature-bundles.md            # 配套完整性:闭环思考程序 + 确认分级
    ├── patterns.md                   # 可复用模式现货:错误格式/校验/请求层/表单/三态(契约 + Next.js/Vue 示例)
    ├── security-checklist.md         # 安全基线:写接口/表单/查询/上传时默认执行
    ├── delivery-checklist.md         # 交付自查:测什么、验什么、如实汇报
    └── site-essentials.md            # 站点级能力 + 视觉身份 + favicon 时机与做法
```

`SKILL.md` 是入口,按情况把 Claude 路由到对应的 reference 文件;细节都下沉在 `references/`,保持入口精简。

## 工作流一览

| 情况 | Claude 的动作 |
|---|---|
| 微小修改(改文案、调样式) | 改完即止,不触发完整流程 |
| 全新项目 | 走启动对齐,结论写入约定文档 |
| 首次接手已有项目 | 读代码推断约定,复述确认,不重新问卷 |
| 开发任何功能 | 跑闭环思考程序推导配套范围,按体量分级确认 |
| 搭项目骨架 | 列站点级能力清单让用户勾选,并确立视觉身份 |
| 项目基本完工 | 主动发起 favicon 设计 |
| 写接口/表单/查询/上传 | 默认执行安全基线 |
| 汇报"做完"前 | 跑验证 + 过交付自查清单 |

## 如何使用

这是一个 Claude Code Skill。把 `web-dev-workflow/` 目录放进 Claude Code 的 skills 目录即可(个人级 `~/.claude/skills/`,或项目级 `.claude/skills/`):

```bash
# 个人级安装(对所有项目生效)
git clone https://github.com/junanxx9527-rgb/skill-web-dev-workflow.git
cp -r skill-web-dev-workflow/web-dev-workflow ~/.claude/skills/
```

之后凡是涉及网站 / Web 应用开发的任务,Claude 会按 `SKILL.md` 的 `description` 自动触发本 skill。

## 许可

个人项目,按需取用。
